# iPhone Safari向け 反射ルートシミュレーター v0.3

## 使い方
1. このフォルダー内のファイルをまとめてHTTPS対応の静的ホスティングにアップロードします。
2. iPhoneのSafariで公開URLを開きます。
3. 「写真・画像を選択」からスクリーンショットを選びます。
4. 必要ならSafariの共有メニューから「ホーム画面に追加」を選びます。

## 含まれるファイル
- index.html: シミュレーター本体（iPhone向け画像読み込み改善済み）
- manifest.webmanifest: ホーム画面起動用のWebアプリ設定
- sw.js: オフラインキャッシュ
- icon-192.png / icon-512.png: ホーム画面アイコン

## 注意
- PWA機能とService WorkerはHTTPSのWeb公開が必要です。ファイルアプリから直接開く方式では使えません。
- iPhone Safariの写真・ファイル選択はOSの選択画面を使います。
- 画像の敵・ブロック自動認識や本編と同一の物理演算は未実装です。
